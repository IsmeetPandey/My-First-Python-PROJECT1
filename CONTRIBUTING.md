# Contributing

This is an early Python project, so contributions should stay simple, readable, and easy to verify.

## Workflow

1. Create a focused branch.
2. Make one understandable change at a time.
3. Prefer clear Python over unnecessary complexity.
4. Test the changed behavior before opening a pull request.
5. Explain the change and verification steps in the pull request.

## Safety

Never commit passwords, API keys, personal information, or other secrets.

## Pull requests

Bug fixes, beginner-friendly documentation, tests, and small usability improvements are welcome. Keep pull requests focused and explain what a reviewer should check.
