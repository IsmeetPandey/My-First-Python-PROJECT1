# Project Notes

This repository is a small Python project and is intentionally kept approachable for someone learning the basics.

## Working rhythm

1. Keep each change focused on one behavior or documentation improvement.
2. Run the available checks before opening a pull request.
3. Explain what changed and why in the pull request description.

## Safety basics

Do not commit passwords, API keys, personal access tokens, or other secrets. Use local environment variables or another secure secret store for values that should not live in source control.

## Learning principle

Readable code is more valuable here than clever shortcuts. Prefer simple functions, clear names, and small changes that are easy to understand and reverse.

## Next improvements

Future contributions can add tests around the existing behavior, improve input validation, and document examples for new learners without making the project unnecessarily complex.
